# Fli-lines1

A lightweight 3D city-building game inspired by classic simulation and sandbox builders.

Play now: [Fli-lines on GitHub Pages](https://blobse-dev.github.io/Fli-lines1/)

## Features
- Build a small town or larger city from the ground up
- Place roads, structures, and neighborhood layouts
- Explore a simple 3D environment with a clean, browser-based interface
- Designed to run as a fast static app on GitHub Pages

## Local development
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

## Publish to GitHub Pages
```bash
npm run deploy
```

This project is configured with a GitHub Pages base path and a production build pipeline for easy publishing from the repository.
